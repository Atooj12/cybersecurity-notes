Anotações do curso **SOC Fundamentals**, com os conceitos base sobre a estrutura, as funções e as ferramentas de um Security Operations Center (SOC).

## Resumo geral

O curso apresenta a base de como funciona um SOC na prática: os diferentes modelos de operação (interno, remoto, terceirizado), o tripé que sustenta uma operação eficiente (pessoas, processos e tecnologia), as funções de cada profissional do time, as principais ferramentas usadas no dia a dia (SIEM, EDR, SOAR) e os erros mais comuns cometidos por analistas iniciantes durante investigações.
